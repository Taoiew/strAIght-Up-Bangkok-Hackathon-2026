# are managed in package.json and package-lock.json instead of Python pip.
#
# Runtime requirements:
# - Node.js 20 or newer
# - npm 10 or newer
# - Docker Desktop, only for local Docker database mode
# - PostgreSQL database, Supabase PostgreSQL recommended
# - OpenAI API key or Gemini API key
# - Auth.js secret

# Fastest local start:
